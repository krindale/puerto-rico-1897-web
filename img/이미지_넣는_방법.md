# 타일 이미지 넣는 방법

규칙서 PDF에서 캡처한 이미지를 **이 폴더(`img/`)** 에 아래 파일명(PNG)으로 저장하면
게임 화면의 해당 타일에 자동으로 표시됩니다. 파일이 없으면 텍스트 타일로 표시되므로
일부만 넣어도 됩니다. **파일명에 띄어쓰기는 넣지 마세요.**

## 참고
- 권장 비율: 가로형(예: 300×200px 내외). 타일 칸에 맞게 자동으로 잘려 표시됩니다(`object-fit: cover`).
- 규칙서 마지막 페이지를 흰 배경으로 추출한 `푸에르토리코1897_건물개요_흰배경.png`(300 DPI)에서
  건물 카드를 잘라 쓰면 깔끔합니다.
- PNG 대신 JPG를 쓰려면 게임 파일(`푸에르토리코1897_게임.html`)의 `imgTag` 함수에서 `.png`를 `.jpg`로 바꾸세요.
