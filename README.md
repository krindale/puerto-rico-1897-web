# 푸에르토리코 1897 — 웹 플레이

<보드게임 &lt;푸에르토리코 1897&gt;>의 기본 게임 규칙을 브라우저에서 그대로 즐길 수 있게 만든 팬 프로젝트입니다.
빌드 도구·서버·패키지 매니저 없이 정적 파일만으로 동작합니다.

## 실행 방법

- **온라인**: https://krindale.github.io/puerto-rico-1897-web/ (main 브랜치에 푸시하면 자동 배포)
- **로컬**: `game.html` 파일을 더블클릭해서 브라우저로 열면 바로 플레이할 수 있습니다.
  `index.html`은 규칙 설명 + 플레이 탭 통합 페이지입니다.

- 2~5인, 각 자리를 **AI / 친구** 중 선택
- **온라인 멀티플레이** — 방을 만들면 6자리 코드가 나오고, 친구가 코드로 들어옵니다 (계정 불필요, 채팅 포함)
- 기본 게임 규칙 전체 구현 (역할 7종, 건물 23종, 2인 특별 규칙, 게임 종료·최종 점수 계산)
- 진행 상황은 `localStorage`에 자동 저장되어 새로고침해도 이어집니다 (온라인 게임은 서버에 저장)

## 구성

```
index.html      규칙 설명 페이지 (소개/방법/상품/건물/종료 + 플레이 탭) — 본문 HTML만
game.html       게임 본체 셸 — css/·js/ 를 순서대로 로드
css/            스타일 (intro.css 소개 페이지 · game.css 게임)
js/             스크립트 (intro.js 소개 페이지 · 나머지는 게임 코드, 로드 순서는 game.html 참고)
img/            역할·건물·농장 타일 이미지
tools/smoke.js  헤드리스 스모크 테스트 (node tools/smoke.js)
```

### 타일 이미지 추가/교체

`img/이미지_넣는_방법.md` 참고. `img/역할_개척자.png`, `img/건물_소형과일공장.png`,
`img/농장_옥수수.png` 형식(띄어쓰기 없이)으로 저장하면 자동으로 적용되고,
파일이 없는 항목은 텍스트로 대체 표시됩니다.

## 안내

- 비공식 팬 프로젝트이며, Ravensburger / 코리아보드게임즈와 무관합니다.
- 게임 내 타일 일러스트는 정식 발매판 규칙서에서 개인적으로 발췌한 것으로, 원작사의 저작권 자산입니다.
  상업적 목적으로 사용하지 마세요.
